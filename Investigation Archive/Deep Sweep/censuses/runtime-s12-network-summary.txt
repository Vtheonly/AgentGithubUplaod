## Root-cause seam (static, file:line)

`online-detector.ts:171-182` — `getOnlineDetector()` resolves `probeUrl = resolveProbeUrl(supabaseUrl)` from the module-scope `supabaseUrl` (the canonical-fallback chain, same family as C-20: `supabase-client.ts:33-38,120`). The t-050 design comment says "no probe at all when the Supabase URL is unconfigured (mock/dev mode)" — but with the canonical fallback the URL is never unconfigured, so the probe runs in mock mode. This is the THIRD member of the two-gates seam family (the data layer's `useSupabase` toggle vs the connectivity layer's canonical-URL resolution): C-20 (dev defaults live), BUG-042 (Configuration tab loop gate), and now the detector drip.

Fix direction (plan only): resolve the probe URL from the same effective runtime config the data layer uses (respect `useSupabase=false` / local config), or expose an explicit offline/local-first mode that disables probing; keep the 5 s throttle + 30 s interval as-is.
