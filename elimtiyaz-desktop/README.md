## Quick Start

```bash
npm install
npm run dev          # Vite dev server (HMR)
npm run electron:dev # Vite + Electron concurrent
npm test             # Run test suite (1,420/1,444 passing)
npm run typecheck    # TypeScript check (0 errors)
npm run build        # Production build
```

For full setup, configuration, and deployment instructions, see [`restore-reports-docs/architecture.md`](./restore-reports-docs/architecture.md).
